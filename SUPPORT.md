# Unio Collector support

Unio Collector is source-available under the custom [LICENSE](LICENSE).
The canonical public website is [Tevari Cloud](https://tevaricloud.com/).
Public repository participation does not create an SLA, response-time commitment
or support entitlement.

- **Bugs in the public Unio Collector code:** use the
  [bug issue form](../../issues/new?template=bug_report.yml). Include the version
  and a reproducible example using synthetic, non-sensitive data.
- **Feature suggestions:** use the
  [feature form](../../issues/new?template=feature_request.yml). Suggestions are
  subject to maintainer review; submission does not promise acceptance or implementation.
- **Security vulnerabilities:** never open a public issue. Use GitHub's private
  **Security → Report a vulnerability** path described in [SECURITY.md](SECURITY.md).
- **Commercial or service enquiries about Unio or Tevari Cloud:** use the normal
  contact route through the [Tevari Cloud contact page](https://tevaricloud.com/contact).
- **General AWS support:** account administration, AWS service troubleshooting
  and general AWS advice are outside this project's support scope. Use your
  usual AWS support channels.

Never submit AWS credentials, access keys, session tokens, AWS account IDs,
real customer evidence bundles, decrypted evidence, privacy vaults, passphrases,
recovery material or other secrets in public issues, pull requests or comments.
Use synthetic reproductions and sanitise output and logs before sharing them.
Removing identifiers alone does not make real evidence safe to publish.

Participation follows the [code of conduct](CODE_OF_CONDUCT.md). Contribution
expectations are in [CONTRIBUTING.md](CONTRIBUTING.md).
